# Student Performance Analysis Dashboard

## Project Overview

This project analyzes student performance across different subjects using Microsoft Excel.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Design

## Features

* Student-wise Performance Analysis
* Subject-wise Performance Analysis
* Interactive Slicers
* KPI Metrics
* Dynamic Dashboard
